CONTINUACIÓN A LA PRÁCTICA 3

Objetivo

Creará programas que utilicen la implementación de listas, uso de lambda, determinación de características eager y lazy..


Actividades


Analizar los programas que se presentan para crear otros programas que se piden.


Cuestionario


Pregunta 1. Realizar el programa que implemente una lista con características eager. Basarse en el programa Lazy2.py.


Pregunta 2. Crear un programa que use la lambda para calcular la suma de dos listas: una de 100 y otra de 200 números. Basarse en el programa Lazy4.py. Que imprima una lista a la vez.


Pregunta 3. Crear un programa que entregue una lista de 15 números y que a cada elemento le sume 5. Basarse en el programa Lazy3.py.


Pregunta 4. Realizar el programa que entregue una lista con elementos no repetidos a partir de una lista entregada. Basarse en los programas LisNoRep.py, NumNoRep.py. La lista de entrada es: ["Abecedario", "Lista", "Nombres", Estudiantes", "Abecedario", "Asignaturas", "Calificaciones", "Abecedario", "Puntos", "Saberes", "Escuela", "Asignaturas", "Abecedario"]
