En programación funcional se hace uso de la recursión para sustituir a los bucles.


La recursión de cola es cuando una función lo último que ejecuta es otra función. Se muestra en el siguiente ejemplo una recursión de cola:


     int metodoA() {
         int x = C;
         return metodoB(x);
     }

Un ejemplo práctico es el cálculo del factorial de un número, que se presente a continuación:


     int metodoFac(n) {
         if(n == 0)
             return 1;
         else
             return n * metodoFac(n - 1);
     }

De otra manera la misma función para calcular el factorial de un número, es:


     int metodoFac1(n) {
         return metodoFacCola(n,1);
     }
     
     int metodoFacCola(n.a) {
         if(n == 0)
             return a;
         else
             return metodoFacCola(n - 1,n * a);
     }

Para crear una lista con valores, se hace de la siguiente forma:


     List<Integer> nombreLista = Array.asList(Valores numéricos);

O de esta forma:


     List<Integer> nombreLista = Array.of(Valores numéricos);

Si se quiere crear una variable que reciba una lista, se hace de la siguiente forma:


     List<Tipo de dato> variableLista = new List<>();

Si se quiere crear una variable que reciba una lista con una clase calificadora, se hace de la siguiente forma:


     List<ClaseCalificadora> variableLista = new List<>();

Las listas se pueden pasar como argumentos a funciones o métodos, de la siguiente forma:


     public void setLista(List<ClaseCalificadora> variableLista) {
         this.variableLista = variableLista;
     }

Usar una lista como argumento para un método get, se hace de la siguiente forma:


     public List<ClaseCalificadora> getLista() {
         return variableLista;
     }

Usar una lista como argumento para un método cualquiera diferente de set y get, se hace de la siguiente forma:


     public ClaseCalificadora nombreMetodo(ClaseCalificadora nombreObjeto) {
         this.variableLista.funcionUsada(nombreObjeto);
         return this;
     }

    Concepto 5. Pequeña historia de los lenguajes de programación.


    Código máquina y lenguaje ensamblador se usaron de 1940 a 1950, el código máquina es una serie de instrucciones binarias, el lenguaje ensamblador se representa con mnemotecnia. La programación procedimental (Fortran, Cobol, C) de 1950 a 1970, esta se enfoca en dividir los programas en programas más pequeños, en procedimientos o funciones reusables, y emfatiza la ejecución secuencial y el control del flujo. La programación orientada a objetos (Smalltalk, C++, Java) de 1980 a 1990, esta introduce conceptos como: encapsulamiento, herencia, y polimorfismo, con lo que se mejora la organización y la reutilización del código. La programación lógica (Prolog) de 1970 a la fecha es una forma de programar con hechos y reglas, este paradigma se usa para IA, y representación del conocimiento. La programación funcional (Lisp, Haskell, JavaScript) del 2000 a la fecha, esta emfatiza la inmutabilidad, funciones puras, y funciones de orden superior, lo que se usa para programación concurrente y paralela.
