1.1.1 CRITERIOS DE LOS LENGUAJES DE PROGRAMACIÓN

Características de los lenguajes de programación


El lenguaje como herramienta.


El lenguaje es una herramienta que te permite implementar un paradigma de programación.


Provee la sintaxis y la semántica para escribir el código que entienda la computadora.


Especifica el conjunto de reglas e instrucciones que usas para comunicarte con la computadora.


Programming paradigm, James Allen, 2025


Aplicación de los lenguajes de programación.


La siguiente figura muestra las características más relevantes de un lenguaje de programación, que lo hacen amigable con el programador. Esto se hace poniendo énfasis en la sintaxis y la semántica.





Por su necesidad: los lenguajes de programación deben atender las necesidades de los programas: el cambio de estado, la secuencia de instrucciones, el control.


Por su objetivo: el lenguaje de programación sirve para comunicarse con la computadora para solicitar una operación o una información.

Paradigma de programación


Es la forma fundamental de pensar para escribir y organizar el código. Es una mentalidad. Es como se resuelve un problema, se estructura una solución y como se razona acerca de un sistema. No es un estilo de escribir código.


El paradigma de la programación es una forma de pensar que guia como estructurar y resolver problemas mediante código. Esto te muestra como abordar la solución de un problema: que conceptos, que patrones debes usar, y como debes administrar la complejidad.


Es la forma como se articulan matemáticas, ciencia y tecnología para llegar a un tipo específico de solución.


Programación imperativa con lenguaje C, Omar Iván Trejos Buriticá, 2017


El paradigma es un modelo mental o cosmovisión. Es el lente por medio del cual definimos los problemas y construimos los programas. Para lo cual, los paradigmas son los siguientes:


  1. Paradigma imperativo.
  2. Paradigma orientado a objetos. Cuando los sitemas de software se hacen más complejos, especialmente con las interfaces gráficas y los requerimientos de simulación, se requirio modelar entidades del mundo real con mayor naturalidad. Se aplican los conceptos de encapsulamiento, herencia y polimorfismo.
  3. Paradigma declarativo.
  4. Paradigma reactivo.


Programming paradigm, Michael Williams, 2025


Formas de programar


Programar no es escribir instrucciones para una computadora. Es resolver problemas por medio de estructuras, lógica, e intenciones.


  1. Programación procedimental Que agrupa instrucciones en funciones o procedimientos reusables.
  2. Programación estructurada Es más clara, con más código mantenible mediante la aplicación de módulos y el control del flujo. Usa el if, while y for.
  3. Programación modular Del paradigma orientado a objetos surge la programación modular. Debido a los conceptos encapsulamiento, herencia y polimorfismo surge la programación modular.
  4. Programación lógica Es el uso de proposiciones lógicas para formular un programa.
  5. Programación reactiva Su funcionamiento se basa en el flujo de datos. Si un dato cambia el programa reacciona de tal manera que no se suspende o se para.



Programming paradigm, Michael Williams, 2025
