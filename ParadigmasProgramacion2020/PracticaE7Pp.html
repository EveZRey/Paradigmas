USO DE MODIFICADORES

Objetivo

Utilizar de manera correcta los modificadores en los programas que se crean en el paradigma orientado a objetos.


Actividades


Analizar el siguiente programa en Java: 


class ClaseA {
    public int x = 100;
    int y = 200;
    private int z = 333;
         
    public void m1() {
        System.out.println("Método 1.");
        ClaseA oa = new ClaseA();
        System.out.println(oa.z);
    }
         
    void m2() {
        System.out.println("Método 2.");
        ClaseA o2 = new ClaseA();
        int valAo2x = o2.x;
        System.out.println(valAo2x);
    }
         
    private void m3() {
        System.out.println("Método 3.");
    }
}
     
class ClaseB {
    void metodoB() {
        ClaseA o = new ClaseA();
        int valXo = o.x;
        int valYo = o.y;
        //int valZo = o.z;
        
        o.m1();
        o.m2();
        //o.m3();
        
        System.out.println(valXo);
        System.out.println(valYo);
    }
}

public class TresClases {
    public static void main(String[] args) {
        ClaseB b = new ClaseB();
        ClaseA oa1 = new ClaseA();
        ClaseC c = new ClaseC();
        oa1.m1();
        //valCy = c.y;
        // System.out.println(valCy);
        //valAz = oa1.z;
                
        b.metodoB();
        c.metodoC();
        //System.out.println(valAz);
    }
}

Cuestionario

Pregunta 2. mostrar el uso del modificador indefinido adaptando el programa que se analizó.
