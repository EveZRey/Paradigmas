Práctica E3

Temario

PARA EL PROYECTO, CREACIÓN DE LISTAS Y USO DE LAMDA

Objetivo

Creará programas que utilicen la implementación de listas y uso de lambda.


Actividades


Analizar los programas que se presentan en la parte de sugerencias.


Cuestionario


Pregunta 1. Realizar el programa que implemente una lista de productos, tales como: papel higienico, jabón, cloro, sardinas, queso blanco, jamón, y los que se les ocurra (4 más).


Pregunta 2. Crear un programa que use la lambda para calcular el área de un triángulo.


Pregunta 3. Crear un programa que use la lambda que presente el número mayor que ingreses por teclado.


Pregunta 4. Realizar el programa que implemente en una lista de estudiantes con calificación.
