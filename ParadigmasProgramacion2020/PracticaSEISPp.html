CONSTRUCCIÓN DE CLASES Y OBJETOS

Objetivo


Utilizará el paradigma orientado a objetos. Con la finalidad de construir clases y objetos.


Actividades


Actividad 1. construir la clase: Datos.


Actividad 2. construir la clase principal para la clase: Datos.


Actividad 3. construir la clase: Cuadrado, con métodos para calcular área y perimetro.


Actividad 4. construir la clase: Persona, con los métodos para para dar nombre con apellidos y dirección, y el método para presentar su nombre y su dirección.


Cuestionario


Pregunta 1. Para la clase Datos construir los métodos para dar valor a las variables. Presentar el código.


Pregunta 2. Para la clase Datos construir el método principal en una clase diferente a la creada. Presentar el código.


Pregunta 3. Para la clase Cuadrado construir el método principal en una clase aparte para poder calcular el área y el perimetro..


Pregunta 4. Para la clase Persona construir los objetos para cada una de las clases para presentar su nombre y su nombre con dirección.


Pregunta 5. Crear el objeto c para la clase Cuadrado para dar valores a diferenetes cuadrados, con la finalidad de calcular áreas y perimetros.


Pregunta 6. De la clase Persona crear los objetos persona para presentar información como nombre y dirección de diferentes ciudadanos.


Pregunta 7. Usando la clase Datos ejemplificar los conceptos de: variable, variable de instancia, y parámetro o argumento.
