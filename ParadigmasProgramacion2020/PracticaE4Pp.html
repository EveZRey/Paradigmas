Paradigmas de programación
Práctica E4

Temario

PARA EL PROYECTO, CREACIÓN Y MANIPULACIÓN DE LISTAS CON EL USO DE LAMDAS

Objetivo

Creará programas que utilicen la implementación de listas y uso de lambda.


Actividades


Analizar los programas que se presentan en la parte de sugerencias.


Cuestionario


Pregunta 1. Crear un programa que implemente una lista de productos, tales como: papel higienico, jabón, cloro, sardinas, queso blanco, jamón, y los que se les ocurra (4 más). Entregue una lista con los productos ordenados por nombre del producto. Entregue una lista que ordene los productos por precio.

Pregunta 2. Realizar el programa que implemente la creación de listas a partir de una lista base ordenada de productos, tales como: papel higienico, jabón, cloro, sardinas, queso blanco, jamón, y los que se les ocurra (4 más). Las listas creadas deben contener el primer producto y la otra lista el último producto.


Pregunta 3. Crear un programa que implemente una lista de estudiantes con: Asignatura cursada como Paradigmas de programación y Estructuras de datos, Nombre del estudiante, y calificación. Para después entregar una lista de estudiantes que solamente cursen Paradigmas de la programación.


Pregunta 4. Crear un programa que lea las superficies y los cuerpos. Use la lambda que presente el calculo de perimetros, área, y volumen. Para superficies y cuerpos adecuadamente.
